# AI MVP 검증 기록

확인일: 2026-10-23 (Asia/Seoul)

- Java 17.0.19 / 프로젝트 Gradle wrapper 9.4.1 / Spring Boot 4.1.1
- `./gradlew test bootJar`: **71개 테스트 통과**, 실패 0, 오류 0.
- `npm ci` 후 `npm run build`: 통과. 기존 전체 화면 번들의 500KB 경고는 남아 있다.
- 실제 로컬 서버와 Vite 프록시에서 세션 쿠키, 정책 출처, 동일 요청 재시도 결과 확인.
- 브라우저에서 해결책 모드 → 정책 질문 → 답변과 공식 출처 카드 표시 확인.
- VS Code 설정 JSON 파싱, 실행 스크립트 셸 문법, Git 공백 검사 통과.

## 주요 자동 검증

- 공감 모드와 정책 검색 구분, 안전 표현·부정·교육/인용 표현의 경계.
- 다른 세션의 대화 조회/삭제 거부, 대화 모드 고정, 최초 요청 재시도 중복 방지.
- 동일 요청 번호의 다른 본문 거부, 잘못된 입력과 외부 Origin 거부.
- 일정 초안의 누락 필드, 서울 시간, 잘못된 시각, 이전 초안의 제한된 후속 보완.
- 새 일정이 이전 일정의 시간을 상속하지 않음. 실제 캘린더 저장이나 병원 예약 없음.
- 로컬 HTTP 가짜 Gemini로 구조화 응답, 차단·잘림·잘못된 JSON·429·누락 키·허위 출처 거부.
- 외부 AI 오류 시 데모로 대체하지 않고 오류 반환, 실패 대화 미저장.

## 아직 확인하지 않은 것

- 실제 Gemini API 호출: 이 환경에 API 키가 없어 외부 연결·한국어 답변 품질·계정 한도는 미검증.
- 실제 마이크 음성 인식과 모바일 브라우저별 호환성.
- VS Code 확장 설치 후 F5 디버그 실행. 설정 파일은 준비하고 구문 검사했다.
- MySQL 실접속, 운영 로그인, 공개 배포, 실제 보호자 대상 사용성·위기 대응 검증.

현재 기본 모드는 `demo`이며 고정 규칙에 따른 시연 답변이다. 임상적 안전성이나 정책 수급 자격을 검증한 제품이 아니다.
